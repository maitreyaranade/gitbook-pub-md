## Containers

Python provides a number of container datatypes, both built-in types and
those in the collections module in the Python Standard Library.
Different data containers serve different purposes, provide different
functionality, and present potentially very different computational
performance for similar sorts of calculations.

list: a mutable sequence type, holding a collection of objects in a
defined order (indexed by integers) tuple: an immutable sequence type,
holding a collection of objects in a defined order (indexed by integers)
dict: a mapping type, associating keys to values (unordered, indexed by
keys) set: an unordered collection of unique elements (accessed through
set operations)
